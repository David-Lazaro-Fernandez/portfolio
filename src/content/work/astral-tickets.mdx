## The goal

[Astral Tickets](https://astraltickets.com) is a ticketing platform for live events in Mexico, from concerts and shows to *palenques*. The project, which started under the working name Boletera, covered both sides of selling a ticket: the site where fans find an event and choose their seats, and the tools the team uses to set up events and run the box office.

## Buying a ticket

Fans can browse by category or search by event and city. Each event page has the date, the venue with a map, the event details, and an FAQ.

### Seat maps generated from data

Palenques are round arenas with rings of seating around a central ring. Instead of drawing each venue by hand, the seat map is generated from a JSON description of the venue: each zone lists its angle, number of sections, rows, and price. The map lays out every row as an arc around the center, converting polar coordinates into seat positions, so a 2,400-seat venue becomes a clickable map where staff can select seats and see their zone and price.

### Printed tickets

The box office also sells tickets in person, so the dashboard can print them. Staff fill in the section, row, seat, price, order number, and ticket type, and the dashboard sends it to a print service that produces the physical ticket with its QR code.
